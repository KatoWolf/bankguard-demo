# Демонстрация жюри за 3 минуты

Подготовка: Node 20+, `npm test`, `npm run build`, `npm start`, открыть http://localhost:3000. Интернет, ключи API и реальные данные не нужны после скачивания репозитория. Не открывайте index.html двойным щелчком: используются ES-модули.

1. **0:00–0:30. Проблема.** Ручная проверка переводов имеет ограниченную ёмкость. BankGuard показывает причины риск-балла и цену выбранного порога. Это учебный симулятор, не банковская защита.
2. **0:30–1:10. Объяснение.** Исходный набор 16 сценариев, порог 50. Кейс TX-0002: 75 баллов = 25 за сумму + 15 за получателя + 35 за давление. Комментарий «Демо: требуется независимая проверка», эскалация. Очередь 6 → 5. Ничего не блокируется в банке.
3. **1:10–2:00. Компромисс.** Лаборатория: при пороге 50 — 6 проверок, 1 ложная тревога, 2 пропуска. При пороге 1 — 13 проверок, 6 ложных тревог, 0 пропусков. По 5 минут на кейс: 30 против 65 минут. Это авторская синтетика, не обещание качества.
4. **2:00–2:30. Ограничения.** Вернуть порог 50, ёмкость 0, затем 5. Recall с лимитом предполагает идеального аналитика. Решения журнала не переобучают правила и не меняют лабораторную матрицу.
5. **2:30–3:00. Воспроизводимость.** Сохранить демо-сессию, сбросить, восстановить JSON. Объяснить: оценки пересчитываются, комментарии неподписаны. Стресс-наборы 200/1000 воспроизводятся с seed 2026.

## Проверка без браузера

`npm run demo:verify` печатает JSON для 9 экспериментов: 16/200/1000 операций × пороги 1/50/100. Для чистого JSON: `node scripts/verify-demo.js > demo-report.json`. Нет временных меток, поэтому повторные запуски идентичны. Длительность 5 минут и ёмкость 5 — допущения, не банковские измерения.

## Доступность и резервный план

Есть ссылка «Перейти к содержимому» по Tab, видимый фокус, именованная навигация; при выборе раздела фокус перемещается на заголовок, при выборе операции — в её карточку. Системное предпочтение уменьшенного движения учитывается. Проверки разметки не являются проверкой экранным диктором: клавиатурный и визуальный smoke test пока нужно выполнить вручную.
