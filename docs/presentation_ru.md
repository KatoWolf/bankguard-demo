Необычная сумма • новый получатель

## 7. Простой стек. Честные ограничения.

HTML + CSS + JavaScript ES modules
Node.js: сервер и встроенные тесты
Синтетические сценарии • экспорт CSV/JSON

Нет ML, банковской интеграции и реальных клиентских данных.
Метрики демо не доказывают эффективность в банке.

## 8. Следующий шаг: пилот без влияния на реальные переводы

Обезличенные данные и согласованный baseline

Измерение ошибок, очереди и времени разбора

## 9. Рабочее место аналитика v1.2

Очередь только необработанных тревог: риск по убыванию, ID для равных баллов. Следующий кейс, обязательный комментарий, история решений. Черновики живут в памяти вкладки.

16 сюжетных сценариев и воспроизводимые стресс-наборы 200/1000 операций с seed 2026. Это искусственные данные, не независимая проверка качества.

---

## 10. Цена порога на конкретном примере

| На 16 сценариях | Порог 50 | Порог 1 |
|---|---:|---:|
| Ручных проверок | 6 | 13 |
| Ложных тревог | 1 | 6 |
| Пропущенных fraud-сценариев | 2 | 0 |
| Нагрузка при 5 мин/кейс | 30 мин | 65 мин |

Ёмкость аналитиков задаётся для всей выборки. Recall с лимитом предполагает идеальную проверку выбранных случаев, не измеряет реальную эффективность человека.

---

## 11. Воспроизводимость и доверие

JSON эксперимента: метрики, baseline, допущения, лимит, seed. JSON сессии: встроенный набор, параметры, журнал. Импорт пересчитывает риск и проверяет поля; файл не подписан и не доказывает подлинность комментариев.

58 автоматических теста, включая 32 комбинации правил, границы, CSV, сессии, гонки импорта, лимиты больших журналов и CLI-демо. Тесты и сборка прошли в GitHub Actions на Windows/Ubuntu × Node.js 20/22/24. Состояние актуального запуска — во вкладке Actions репозитория.

`npm run demo:verify`: 9 одинаково воспроизводимых экспериментов без браузера. Ручная браузерная проверка последней версии пока не подтверждена из-за ограничения рабочей среды.
